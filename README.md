# Shaik Maleeha Aiman — AI/ML Engineer Portfolio

A modern, high-performance portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## 🌟 Features & Design

- **High-Definition Video Hero**: Full-screen looping background video with autoPlay, muted, loop, and playsInline attributes.
- **Dynamic ShinyText**: 100-degree animated gradient text sweep powered by Framer Motion.
- **Glassmorphic Navigation**: Floating pill navigation bar with custom circular identity logo and mobile responsive drawer.
- **Technical Skills Matrix**: 6 clean categories covering Programming, AI & Technology, Databases, Developer Tools, Design Tools, and Productivity Tools.
- **Passions & Interests**: Interactive grid of 9 areas of interest across emerging technologies.
- **Verified Credentials**: Verified workshop and hackathon participation certificates.
- **Dedicated "Let's Connect" Section**: Modern interactive grid with clickable cards for LinkedIn, GitHub, Email (`mailto:`), plus placeholder handling for Figma and Resume PDF.
- **Strict Adherence**:
  - Identified strictly as an **AI/ML Engineer**.
  - No student references.
  - No invented awards, projects, or metrics.
  - No personal photo or home address.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or pnpm

### Installation

```bash
# Clone the repository and navigate into the directory
cd d:/portfolio

# Install dependencies (already installed)
npm install
```

### Running Locally

```bash
# Start development server
npm run dev
```

Open your browser at `http://localhost:5173`.

### Production Build

```bash
# Typecheck and build for production
npm run build

# Preview production build locally
npm run preview
```

The compiled static assets are located in the `dist/` directory, ready for immediate deployment on GitHub Pages, Vercel, Netlify, or any static host.
